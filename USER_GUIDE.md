# Todo Application User Guide

## Getting Started

### Account Registration
1. Navigate to the application homepage
2. Click on the "Sign Up" button
3. Enter your email address, name, and a secure password
4. Click "Sign Up" to create your account
5. You will be automatically redirected to your dashboard

### Logging In
1. Click on the "Sign In" button
2. Enter your email address and password
3. Click "Sign In" to access your account

## Managing Tasks

### Creating Tasks
There are two ways to create tasks:

#### Via Web Interface:
1. On your dashboard, locate the "Add New Task" form
2. Enter a title for your task (required)
3. Optionally add a description
4. Click "Add Task"

#### Via AI Chatbot:
1. Navigate to the Chat page
2. Type a natural language command such as:
   - "Add a task to buy groceries"
   - "Create a task to call mom tomorrow"
   - "I need to schedule a meeting with John"

### Viewing Tasks
- Your tasks are displayed on the Dashboard page
- Tasks are shown in chronological order by default
- You can filter completed/incomplete tasks using the API (not available in UI yet)

### Updating Tasks
#### Via Web Interface:
1. Find the task you want to update
2. Click the "Edit" button next to the task
3. Modify the title or description
4. Click "Save" to apply changes

#### Via AI Chatbot:
1. Go to the Chat page
2. Type a command like:
   - "Update the 'buy groceries' task to 'buy groceries and milk'"
   - "Change the description of my meeting task"

### Marking Tasks as Complete
#### Via Web Interface:
1. Locate the task you want to mark as complete
2. Check the checkbox next to the task title
3. The task will be visually marked as completed

#### Via AI Chatbot:
1. Go to the Chat page
2. Type a command like:
   - "Mark 'buy groceries' as complete"
   - "Complete the task about calling mom"
   - "I finished the meeting task"

### Deleting Tasks
#### Via Web Interface:
1. Find the task you want to delete
2. Click the "Delete" button next to the task
3. Confirm the deletion if prompted

#### Via AI Chatbot:
1. Go to the Chat page
2. Type a command like:
   - "Delete the 'buy groceries' task"
   - "Remove the task about calling mom"

The AI chatbot allows you to manage your tasks using natural language. Here are some examples of what you can do:

### Task Creation Examples:
- "Add a task to call the doctor"
- "Create a task to finish the report by Friday"
- "I need to remember to pay the electricity bill"

### Task Update Examples:
- "Change the task 'grocery shopping' to 'weekly grocery shopping'"
- "Update the description of my workout task to include yoga"

### Task Completion Examples:
- "Mark the workout task as complete"
- "I finished the laundry task"

### Task Deletion Examples:
- "Delete the task about cleaning the garage"
- "Remove the old project task"

## Security Best Practices

1. Use a strong, unique password for your account
2. Log out when using shared computers
3. Never share your account credentials
4. Regularly review your tasks for any unauthorized changes

## Troubleshooting

### Common Issues:

**Issue**: Cannot sign in
**Solution**: Verify your email and password are correct. Reset your password if needed.

**Issue**: Tasks not appearing after creation
**Solution**: Refresh the page. If the issue persists, check your internet connection.

**Issue**: AI chatbot not responding
**Solution**: Check your internet connection and try again. Ensure your request is clear and specific.
